# Nostrum care data consulting 

Analysis of NostrumCare's contract, payment (Stripe), and reimbursement data, structured into four main sections: data quality, statistical analysis, customer segmentation, and data engineering.

**Author:** Gildas EDENAKPO  
**Languages & Tools:** Python (pandas, scikit-learn, matplotlib) and SQL (SQLite)

## Reproductibility of results

```bash
python -m venv .venv
.venv\Scripts\activate          # under macOS / Linux : source .venv/bin/activate
pip install -r requirements.txt
```

Run the notebooks in the specified order: each notebook uses the outputs generated by the previous one (Notebook 01 produces the cleaned tables, while Notebook 03 generates the customer segments used by Notebook 04).

```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/01_data_quality.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/02_statistiques.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/03_segmentation_clients.ipynb
jupyter nbconvert --to notebook --execute --inplace notebooks/04_data_engineering.ipynb
```
